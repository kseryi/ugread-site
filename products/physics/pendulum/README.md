# Симулятор Математичного Маятника (Mathematical Pendulum Simulator)

**Проект розроблено авторським колективом фізиків та вчителів фізики.** 
Візуальне оформлення інтерфейсу та костомний CSS-код проекту повністю згенеровані, оптимізовані та стилізовані з допомогою **штучного інтелекту (AI)**.

Цей застосунок є інтерактивним інструментом для високоточного моделювання та фізичної аналітики коливальних систем. Проект створено як автономний локальний додаток (Autonomous Local App), призначений для використання на уроках фізики, під час проведення шкільних лабораторних робіт, лекцій або для самостійного вивчення механіки учнями та студентами.

---

## Мета проекту
Поєднання глибокої фундаментальної фізики з передовими технологіями розробки інтерфейсів. Симулятор дозволяє візуалізувати складні процеси нелінійної механіки, які важко або неможливо продемонструвати на звичайному шкільному обладнанні (наприклад, коливання на інших планетах, за екстремальних кутів відхилення або з урахуванням опору повітря).

---

## Основні можливості (Фічі)

### 1. Точний фізичний рушій (Physics Integrator)
* **Інтегрування методом Рунге-Кутти 4-го порядку (RK4):** На відміну від спрощених лінійних моделей, симулятор розраховує реальний рух маятника без обмеження малих кутів.
* **Порівняння періодів:** У режимі реального часу розраховується та зіставляється **теоретичний період (формула Гюйгенса)** для малих кутів та **точний нелінійний період (наближення Борда)** для великих амплітуд.
* **Багатофакторна симуляція:** Можливість динамічно змінювати довжину нитки ($l$), масу тягарця ($m$), коефіцієнт опору повітря ($c$) та прискорення вільного падіння ($g$).

### 2. Віртуальна лабораторія та аналітика
* **Інтерактивне полотно (Canvas):** Користувач може безпосередньо мишкою або пальцем на екрані перетягувати тягарець, щоб задати будь-який початковий кут.
* **Віртуальний секундомір лабораторної:** Модуль для проведення експериментів. Дозволяє відраховувати 10 повних коливань, фіксувати емпіричний період та автоматично вираховувати відсоток похибки відносно теорії.
* **Динамічні графіки (3 режими):**
  * *Хвильові графіки* (зміна кута відхилення $\theta$ та кутової швидкості $\omega$ з часом).
  * *Баланс енергій* (кінетична $E_k$, потенційна $E_p$ та збереження повної механічної енергії $E_{tot}$).
  * *Фазовий портрет* (траєкторія системи у фазовому просторі координата/швидкість).
* **Експорт даних:** Можливість вивантаження масиву точок симуляції у формат **CSV** для подальшого аналізу в Excel або аналогічних програмах.

### 3. Методична та інтерфейсна підтримка
* **Вбудований довідник:** Інтегровані методичні вказівки та фундаментальні формули безпосередньо всередині програми.
* **Готові шаблони експериментів:** Швидкий запуск режимів (Малі кути, Великі кути, Гравітація Місяця, Опір повітря, Маятник Фуко, Розмах 170°).
* **Мультимовність та кастомізація:** Повна підтримка української та англійської мов інтерфейсу, а також перемикання між темною та світлою темами.

## Дизайн, стилізація та джерела (AI Generated)
Особливістю технічної реалізації інтерфейсу є те, що **зовнішній вигляд додатку та його стилістика були створені штучним інтелектом**:
* **Дизайн-концепція інтерфейсу:** Штучний інтелект спроектував сучасну панель керування ("Dark Tech Dashboard"), колірну палітру, інтерактивні повзунки та адаптивну сітку на основі сучасної дизайн-системи відомого фреймворку [Tailwind CSS](https://tailwindcss.com).
* **Оптимізація коду стилей:** Весь CSS-код згенеровано та скомпільовано ШІ безпосередньо в один локальний файл `style.css`. Завдяки цьому додаток має всі переваги адаптивного дизайну Tailwind CSS, але залишається на 100% автономним і не виконує жодних зовнішніх запитів до інтернету (Zero Network Dependencies).

---

## Технологічний стек
Проект розроблений за принципом **Zero Dependencies** — додаток не потребує зовнішніх фреймворків чи бібліотек, що робить його запуск миттєвим.

* **Логіка та розрахунки:** Чистий JavaScript (Vanilla JS, ES6), HTML5 Canvas API для малювання маятника та графіків.
* **Стилі:** CSS3, згенерований за допомогою штучного інтелекту.
* **Шрифти:** Системний стек `Inter` для максимальної читабельності наукових формул та цифр.

## Встановлення та запуск
Оскільки додаток є автономним (Autonomous Local App), він не потребує встановлення та сервера.

1. Завантажте або склонуйте репозиторій:
   ```bash

   ```
2. Відкрийте папку проекту.
3. Просто двічі клацніть на файл `index.html` у будь-якому браузері.
