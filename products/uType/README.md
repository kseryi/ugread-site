# 🐛 Клавіатурний тренажер — Хробачки (uType)

Сучасний інтерактивний клавіатурний тренажер-гра для дітей та дорослих, розроблений для захоплюючого та методично вивіреного освоєння **сліпого десятипальцевого друку** українською та англійською мовами.

---

## 🌟 Основні можливості та філософія

- **Гейміфікація замість нудних вправ**: гравець керує обраним героєм, який долає перешкоди, збирає монети та рятується від невгамовного хробака, що наздоганяє ззаду.
- **Дві повноцінні мови**: повна підтримка української розкладки (**ЙЦУКЕН**) та англійської розкладки (**QWERTY**).
- **11 класів складності (від початківця до профі)**:
  - **1 клас (Класичний тренажер)**: повний курс із 40 структурованих класичних уроків сліпого набору (опорні клавіші, пальці обох рук, ряди клавіатури, розділові знаки, Shift, цифри).
  - **2–11 класи**: тематичні зв'язні тексти, адаптовані за віковими та мовними категоріями (природа, казки, історія, наука, комп'ютерні технології).
- **Вбудований конструктор власних уроків**: створення індивідуальних рівнів з генерацією та збереженням у форматі JSON.
- **Підтримка офлайн-роботи та локальних файлів**: можливість завантажувати будь-які JSON-уроки безпосередньо через браузер.

---

## 🎮 Ігровий процес та механіка

1. **Рух персонажа та механіка платформ**:
   - **Маленькі літери**: персонаж біжить прямо по доріжці вперед.
   - **Велика літера (Shift)**: персонаж здійснює **стрибок угору** на вищу платформу.
   - **Пробіл (`Space`)**: стрибок через **прірву** між платформами.
   - **Enter (`↵`)**: спуск персонажа на **рівень нижче**.
2. **Переслідувач (Хробак)**:
   - Якщо гравець друкує занадто повільно або часто помиляється, хробак наближається.
   - 6 рівнів швидкості хробака на вибір:
     - `0` — 🛑 Нерухомий (безпечний режим для новачків і першачків)
     - `1` — 🐢 Дуже повільний
     - `2` — 🐛 Повільний
     - `3` — ⚡ Середній (стандартний баланс)
     - `4` — 🔥 Швидкий
     - `5` — 🚀 Максимальний (випробування для майстрів)
3. **Битви зі словами-босами**:
   - Наприкінці або в ключових моментах рівня з'являється слово-бос із власним запасом здоров'я (HP).
   - Точний набір літер завдає ударів босу та знищує його, відкриваючи фініш рівня.

## 📚 Структура класичного курсу (1 клас — 40 уроків)

Для 1-го класу встановлено окремий покроковий курс сліпого друку з 40 фундаментальних уроків:

| Етап | Уроки | Опис та клавіші |
|------|-------|-----------------|
| **Етап 1: Опорний базовий ряд** | 01–07 | Опорні клавіші з мітками (`А` / `О` в UA, `F` / `J` в EN), суміжні вказівні (`В/Л`, `D/K`), середні (`І/Д`, `S/L`), безіменні (`Ф/Ж`, `A/;`), мізинці (`П/Р`, `G/H`), правий край (`Є`), закріплення ряду. |
| **Етап 2: Верхній ряд** | 08–14 | `Е/Н` (`R/U`), `К/Г` (`E/I`), `У/Ш` (`W/O`), `Ц/Щ` (`Q/P`), `Й/З/Х` (`T/Y`), літера `Ї` та комбіновані вправи двох рядів. |
| **Етап 3: Нижній ряд** | 15–20 | `М/И` (`V/M`), `Т/Б` (`C/,`), `С/Ч` (`X/.`), `Я/Ю` (`Z//`), знак м'якшення `Ь` (`B/N`), повний алфавітний дрил. |
| **Етап 4: Розділові знаки** | 21–25 | Крапка `.`, кома `,`, апостроф `'`, знак оклику `!`, знак питання `?`, тире `—`, двокрапка `:`, лапки `«»` / `""`. |
| **Етап 5: Shift та великі літери** | 26–27 | Робота лівого та правого Shift, географічні назви, власні імена. |
| **Етап 6: Цифровий ряд** | 28–30 | Ліва рука `1..5`, права рука `6..0`, повний ряд `0..9`. |
| **Етап 7: Швидкість та майстерність** | 31–40 | Часті біграми/триграми, слова з подвоєнням, довгі слова, прислів'я, діалоги та випускний іспит. |

## 🦸 Персонажі (Векторні SVG-герої)

Гравець може вибрати улюбленого героя перед кожною грою:
🐼 Пандочка (Бамбуковий майстер) — миле бамбукове ведмежатко у затишному теплому шарфику з золотим дзвіночком та пагінцем соковитого бамбука в лапці.
⚔️ Лицар (Захисник замку) — відважний воїн у сталевих лицарських обладунках із золотим гербом, шоломом з відкритим забралом та яскравим плюмажем, сяючим мечем і геральдичним щитом.
🧝 Ельф (Влучний стрілець) — спритний лісовий рейнджер у смарагдовій туніці, із золотавим волоссям, гострими вушками, сагайдаком стріл за плечима та витонченим магічним луком.
🛡️ Вікінг (Могутній воїн) — грізний північний богатир у шоломі з рогами, хутряній накидці, з вогняною заплетеною бородою, круглим драккарським щитом та широкою бойовою сокирою.
👸 Принцеса (Чарівниця зірок) — витончена володарка королівства в розкішній пишній сукні з пелюстками та золотим орнаментом, рубіновим пояском, діадемою у золотому волоссі та магічною паличкою, що випромінює зоряне сяйво.

## 🎨 Тематичні локації та світи

У грі доступно 5 барвистих атмосферних фонів з адаптивною колірною гамою:
- 🚀 **Космос** — зоряне небо, далекі туманності та планети.
- 🏰 **Підземелля** — кам'яні склепіння старовинного замку зі смолоскипами.
- 🌲 **Таємничий ліс** — чарівні смарагдові хащі та світлячки.
- 🌊 **Підводне царство** — глибини океану з коралами та бульбашками.
- 👑 **Королівство** — казковий сонячний краєвид із золотими вежами.

Локацію можна обрати вручну або налаштувати окремо для кожного уроку.

## 📊 Аналітика, прогрес та історія учня

- **Багатокористувацькі профілі**: підтримка кількох учнів на одному пристрої з окремим збереженням результатів.
- **Шкала прогресу уроків**: візуальна сітка пройдених уроків класу із зірочками успіху.
- **Метрики у реальному часі**:
  - `Швидкість (CPM)` — кількість символів за хвилину.
  - `Точність (%)` — відсоток безпомилкових натискань.
  - `Помилки` — лічильник хибних клавіш.
  - `Монети` — накопичені за правильний ритм нагороди.
- **Детальна статистика помилок**: теплова діаграма проблемних літер із порадами, які пальці та клавіші потребують додаткового тренування.
- **Журнал спроб**: хронологічна історія всіх запусків кожного уроку з фіксацією дати, часу, точності та швидкості.

## 🛠️ Конструктор власних уроків

Вбудований редактор дозволяє вчителям або учням за лічені секунди створити новий урок:
- Введіть назву уроку.
- Напишіть текст (рядки розділяються клавішею Enter для створення рівнів).
- Додайте слова-боси за бажанням.
- Одразу запустіть створений рівень кнопкою **«▶ Грати зараз»** або завантажте у форматі `.json` на комп'ютер кнопкою **«📥 Завантажити JSON»**.

## 🚀 Запуск та розробка

Проект працює на сучасному стеку **Vite + React / Modern Vanilla JS & Canvas**:

```bash
# Встановлення залежностей (за потреби)
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка проекту для продакшну
npm run build
```

Після запуску відкрийте у браузері `http://localhost:3000`.
