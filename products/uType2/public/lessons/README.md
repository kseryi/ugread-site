# Класичні уроки для сліпого набору тексту (Touch Typing Lessons)

У цій папці згенеровано 40 класичних структурованих уроків для покрокового освоєння сліпого десятипальцевого друку.

## Методична структура уроків:
1. **Уроки 1–7 (Базовий / опорний ряд)**:
   - А, О (вказівні пальці на рельєфних мітках)
   - В, Л (вказівні)
   - І, Д (середні)
   - Ф, Ж (безіменні)
   - П, Р (розширення)
   - Є (правий край)
   - Закріплення повного домашнього ряду

2. **Уроки 8–14 (Верхній ряд)**:
   - Е, Н
   - К, Г
   - У, Ш
   - Ц, Щ
   - Й, З, Х
   - Ї
   - Комбіновані ритмічні вправи

3. **Уроки 15–20 (Нижній ряд)**:
   - М, И
   - Т, Б
   - С, Ч
   - Я, Ю
   - Знак м'якшення (Ь)
   - Повний алфавітний набір

4. **Уроки 21–25 (Розділові знаки та апостроф)**:
   - Крапка (.)
   - Кома (,)
   - Апостроф (')
   - Знак оклику (!) та знак питання (?)
   - Тире (—), двокрапка (:), лапки («»)

5. **Уроки 26–27 (Великі літери / Shift)**:
   - Лівий та правий Shift, власні назви, географія та імена

6. **Уроки 28–30 (Цифровий ряд 0..9)**:
   - 1..5, 6..0 та комбінації

7. **Уроки 31–40 (Майстерність, ритм та зв'язні тексти)**:
   - Складні біграми (ст, пр, кр, тр)
   - Довгі слова
   - Тематичні зв'язні речення
   - Пряма мова та підсумковий тест

## Формат кожного файлу:
Кожен файл `lessonN.json` містить:
```json
{
  "title": "Назва уроку",
  "text": "Текст уроку",
  "words": ["слово1", "слово2", ...]
}
```

Також створено файл `lessons/index.json` зі списком усіх уроків для простого імпорту в проект.
